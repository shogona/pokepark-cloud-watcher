# チケットカレンダー取得の検証

GitHub Actions の標準Linuxサーバー上で、専用Chromeと仮想ディスプレイを使いチケットカレンダーの在庫を読みます。

現段階は手動の取得検証のみです。定期実行・メール送信は未設定です。取得エラーを空きなしと判定しません。ブラウザーのセッション、個人情報、認証情報を保存・アップロードしません。購入は行いません。

Actions の「チケット取得の検証」から実行し、サマリーとログで結果を確認します。

## 検証結果（2026年11月13日）

- Linux標準サーバー：Chrome起動成功。在庫は取得できず、サイトの「しばらくお待ちください...」画面で待機期限に到達。
- Mac標準サーバー：同じ結果。

どちらも `unknown`（確認不能）として記録しています。サイト側の確認が完了しない具体的な判定理由は不明です。サーバーでの取得が確認できていないため、定期監視・メール通知への移行は未完了です。現在は手動検証だけを実行できます。
